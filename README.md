A tiny Python program that writes one original office joke — a single line under 200 characters — to `/output/entry.txt`. The joke sets up a calendar's one free hour, then turns it into a meeting about being busy. Built for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty.

## Run it

```sh
python3 main.py
```
